# Эрнис Акбаралиев — портфолио

Одностраничное портфолио. Страница открывается пустой, и рой роботов-курсоров собирает её прямо на глазах: летит к блоку, рисует синий каркас, печатает текст и ставит контент, секция за секцией по мере скролла.

Анимация сделана на основе открытого проекта [JaiManjhi/cursor-animation-portfolio](https://github.com/JaiManjhi/cursor-animation-portfolio). Тексты, проекты, фото и русская локализация мои.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3210/?agents=on
```

Клавиши: `T` тур (автоскролл для записи экрана) · `A` агенты вкл/выкл · `P` пауза.

## Как поменять контент

- Все тексты и проекты: `lib/content.ts`
- Фото на главном экране: `public/me-suit.png` (PNG с прозрачным фоном)
- Скриншоты проектов: `public/work/`, фото из путешествий: `public/travel/`

## Стек

Next.js 15 · React 19 · TypeScript · Tailwind CSS v4 · motion · lucide-react

## Деплой

Импортируй репозиторий в Vercel, переменные окружения не нужны.
